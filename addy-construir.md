# Addy Osmani · Mientras construyes

Rebanadas finas, interfaces estables y código más simple.

Lo que pasa entre el spec y el PR. Aquí está la simplificación y el rendimiento que pedías para proyectos ya vivos.

Fuente: [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills)

| Skill | Marca | Qué hace | En tus proyectos |
|---|---|---|---|
| `incremental-implementation` | Instálala | Entrega en rebanadas finas y verificables. Un cambio grande no se escribe de una vez. | OpenSpecs puede salir por detrás de un flag, no como un big-bang. |
| `test-driven-development` | Quédate con el principio | Red, green, refactor para lógica, bugs y cambios de comportamiento. | Tercera variante de TDD del catálogo. Quédate con la de Superpowers o con esta, no con las tres. |
| `api-and-interface-design` | Instálala | Diseña APIs y fronteras de módulo antes de que se congelen. | Los contratos entre front y backend de OpenSpecs, y cualquier endpoint nuevo, se piensan como superficie pública. |
| `frontend-ui-engineering` | Instálala | UI de producción: accesible, responsive, con estado explícito. | Psicorel y cualquier HTML suelto dejan de ser una página que solo se ve bien en tu monitor. |
| `code-simplification` | Instálala | Quita complejidad sin cambiar comportamiento. | Es el núcleo de project-optimizer: menos capas en TypeScript y en Python que ya funcionan. |
| `debugging-and-error-recovery` | Quédate con el principio | Depuración de causa raíz cuando el build, el test o el comportamiento se rompen. | Solapa con systematic-debugging. Usa una. Esta nombra también la recuperación, no solo el diagnóstico. |
| `browser-testing-with-devtools` | Instálala | Prueba en un navegador real: DOM, consola, red y rendimiento. | Psicorel y el front de OpenSpecs se verifican con errores de consola, no con una captura mental. |
| `performance-optimization` | Instálala | Optimiza front, queries y backend solo cuando hay un síntoma o un presupuesto. | LogsKibana y listados de OpenSpecs: primero el N+1 o el payload, no un cache “por si acaso”. |
