# Matt Pocock · Productividad

Afilar la pregunta antes de abrir el editor.

Siete skills de pensamiento. No tocan el repo. Sirven cuando la idea aún está blanda o hay que pasarle el contexto a otro agente.

Fuente: [mattpocock/skills](https://github.com/mattpocock/skills)

| Skill | Marca | Qué hace | En tus proyectos |
|---|---|---|---|
| `grill-me` | Instálala | Entrevista sin tregua un plan o un diseño hasta que deje de tener agujeros. | Antes de abrir OpenSpecs o una lección nueva, te obliga a decir para quién es y qué queda fuera. |
| `grilling` | Quédate con el principio | La misma presión, disparada con cualquier frase de “grill”. | Atajo de voz. Si ya tienes grill-me, no necesitas las dos. |
| `handoff` | Instálala | Compacta la conversación en un documento para que otro agente continúe. | Pasas de Claude Code a Grok o a Antigravity sin reexplicar el spec. |
| `teach` | Quédate con el principio | Te enseña un concepto dentro del workspace, no con un tutorial genérico. | Útil en ai-mastery-course: el agente explica contra el material del repo. |
| `to-questionnaire` | Quédate con el principio | Convierte una decisión que tú no puedes cerrar en un cuestionario para otra persona. | Cuando un cambio de OpenSpecs depende de producto o de un cliente, no inventas la respuesta. |
| `wait-what` | Instálala | Para y reexplica el último mensaje, porque no aterrizó. | Corta las sesiones en las que el agente asiente y luego construye otra cosa. |
| `writing-for-agents` | Instálala | Escribe skills, AGENTS.md y CLAUDE.md para que un agente los ejecute, no para que un humano los admire. | Tus instrucciones de repo dejan de ser un README largo que el agente ignora. |
